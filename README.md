# Project Harness

A tool harness for interacting with LLMs and external utilities. Available tools:
- Weather lookup
- Code execution
- Bash commands
- File reading
- Web search

Project structure:
- src/harness/
  - main.py (entry point)
  - llm.py (model initialization)
  - tools.py (tool definitions)
  - utils.py (helper functions)
  - __init__.py
